# Shared project files

Put a project file here (`Development.brickwood.json`) so Claude can open it and see exactly what you see.

**Get the file:** in the app, open the project, then either
- use **Save to a file…** (bottom bar) and save it in your OneDrive folder; the file updates every time you make a change, or
- on the project list use **More → Export file**.

**Share it:** on github.com open this repository → `shared` folder → **Add file → Upload files** → drop the file in → **Commit changes**. Upload it again whenever you want Claude to see the latest.

Note: this repository is **public**, so anything uploaded here can be seen by anyone. For anything private, attach the file to your chat with Claude instead.
